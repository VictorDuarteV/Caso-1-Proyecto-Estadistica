# Dashboard Caso 1 · FastTrack Logistics

Proyecto Final de Estadística Aplicada a la Investigación (UACH).

## Ejecutar localmente
```
pip install -r requirements.txt
streamlit run app.py
```

## Publicar en Streamlit Community Cloud
1. Sube esta carpeta a un repositorio de GitHub (app.py, estilo.css, datos_logistica_transporte.csv, requirements.txt y la carpeta .streamlit).
2. En share.streamlit.io elige "Create app", selecciona el repositorio y el archivo app.py.
